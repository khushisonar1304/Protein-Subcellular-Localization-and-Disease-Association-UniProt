# Identification of Protein Subcellular Localization and Disease Association Using UniProt

## 1. Project Overview

This project focuses on identifying the subcellular localization of proteins and exploring their association with human diseases using the UniProt database.

UniProt (Universal Protein Resource) is a comprehensive protein database that provides information about protein sequences, functions, structures, localization and biological annotations.

## 2. Objectives

- Identify proteins using the UniProt database.
- Retrieve protein accession numbers and organism information.
- Determine the subcellular localization of selected proteins.
- Explore protein involvement in disease conditions.
- Understand the relationship between protein function, cellular localization and disease.

## 3. Tools and Resources

- UniProt Database
- Web-based protein information retrieval
- Spreadsheet software for data organization (if used)

## 4. Methodology

1. Open the UniProt database.
2. Search for the selected protein.
3. Retrieve its accession number and protein information.
4. Examine the subcellular location annotations.
5. Explore disease-related information and associated annotations.
6. Record and interpret the retrieved information.

## 5. Results and Observations

The protein accession numbers, subcellular localization, functional descriptions and disease-associated annotations are documented in the results section.

## 6. Conclusion

This practical demonstrates the use of the UniProt database for protein annotation, subcellular localization identification and exploration of protein-disease associations.

## 7. Database Reference

UniProt: https://www.uniprot.org/

## 8. Disclaimer

Disease associations reported in protein databases should be interpreted according to their supporting evidence and do not independently establish disease causation.
